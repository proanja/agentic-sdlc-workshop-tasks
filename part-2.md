# Part 2 — Working with SICK primitives

Work with the company primitives repository created in Workshop 2.

## 1. Install and check

Install the SICK primitives you need with APM and check that they are available in Copilot.

## 2. Write a primitive with Primitive Writer

Choose a small, useful primitive that is missing and use the Primitive Writer agent to create it. Review the result, try it on a realistic task in a fresh chat, and refine it based on what you observe.

### 2a. Test and improve existing primitives

Today's additions need further review, testing, and refinement:

- Primitive Writer agent.
- C++ guidelines skill.
- Software-development guideline collection.
- ADR agent.

Choose one and try it on a realistic task. Check discovery and correctness separately, record any problems, improve it, and retest in fresh chats. Decide which improvements belong in the shared repository rather than only in your project.

### 2b. Package a collection

Bundle related primitives into a collection that teams can install with one APM command. Decide what belongs together, document what is included, and verify the installation in a clean workspace.
